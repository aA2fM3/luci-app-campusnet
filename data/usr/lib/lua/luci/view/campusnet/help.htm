CampusNet 校园网认证 · 使用说明

路由器连接校园网 WiFi 后自动完成网页登录，网络断开时会重新认证，无需手动打开认证网页。

一、使用步骤

  1. 在路由器的“无线”设置中连接学校的 WiFi。
  2. 打开“校园网认证”页面，填写 WiFi 名称、学号，选择运营商，填写密码。
  3. 点“保存并应用”，再点“立即测试/登录”，看到“外网状态：在线”即完成。

账号处填写学号即可，无需添加前缀和后缀，系统会自动组成完整账号。

二、字段说明

SSID WiFi 的名称，按这个名称识别使用的无线网络。
BSSID 无线接入点（AP）的 MAC 地址，格式 AA:BB:CC:DD:EE:FF。通常无需填写，留空时按 WiFi 名称识别。
账号前缀 认证协议在账号前添加的固定部分，默认 ,0,，由系统自动添加。
运营商 / 后缀 按所选运营商在学号后添加后缀：联通 @unicom、移动 @cmcc、电信 @telecom；选择校园网时不加后缀。
探活目标 IP 用于判断网络是否连通的地址。默认 223.5.5.5，直接 ping 该地址，不依赖域名解析。
MTU 单个网络数据包的最大大小，标准为 1500。默认关闭、保持 1500；需要时开启并设置为 1280，仅对当前 WiFi 的接口生效。

三、自动运行方式

  • 连接或重连 WiFi 时立即检测，无法连通时重新认证。
  • 按设定间隔定时检测，默认 10 分钟。
  • 路由器开机后自动运行。
  • 优先使用 HTTPS 认证地址，不可用时使用 HTTP 地址。
  • 当服务器提示已在线但无法上网时，会重新登录。

四、常见问题

状态显示“未连接到目标 SSID”？路由器尚未连接该 WiFi，或 WiFi 名称填写不一致，请核对名称。

显示在线但无法上网？可开启自定义 MTU 并设置为 1280，或点“立即测试/登录”重新认证。

账号密码正确但登录失败？确认运营商选择正确；部分学校需填写认证页面的密文。

如何卸载？在“软件包”中卸载，会同时移除开机启动和定时任务。

适用于使用 Dr.COM / eportal 网页认证的校园网环境。
